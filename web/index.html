What you are looking at

RavenOS is a 32-bit x86 kernel written from scratch. Every boot step, driver start and command you run is written to its wyrd timeline. Type timeline to read it.

Your browser is emulating a whole PC with v86, an x86 emulator compiled to WebAssembly. Nothing is installed, and closing the tab turns the machine off.

Runs on v86 (BSD-2-Clause) with SeaBIOS 1.16.2 (LGPL-3.0, which extends the GPL-3.0).
